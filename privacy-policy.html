Privacy Policy for GitHub Code Counter

Last updated: July 26, 2026

GitHub Code Counter counts physical text lines in GitHub repositories. It communicates directly with GitHub's API and does not use a separate developer-operated server.

Information stored locally

  • GitHub personal access token (optional): Stored in Chrome extension local storage until you clear it, uninstall the extension, or clear the extension's site data.
  • Temporary cache: Repository metadata, repository tree data, and numeric line counts are cached for up to one hour. Complete source-file contents are not intentionally retained in the cache.
  • Exclusion preferences: File extensions you choose to exclude remain stored until you remove them or uninstall the extension.

How data is used

The token is sent only to GitHub as an authorization header. Repository data retrieved from GitHub is processed locally in the extension to calculate line counts.

Data retention and removal

Cached analysis data expires after one hour. You can remove the saved token with the Clear button. Uninstalling the extension removes its local extension storage from the Chrome profile.

GitHub API

Requests made by this extension are also subject to GitHub's terms, privacy statement, permissions, and API rate limits.
